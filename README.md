# Ứng dụng Dự Báo Thời Tiết

Ứng dụng Flutter dự báo thời tiết với giao diện đẹp, thân thiện, hỗ trợ đa ngôn ngữ (Anh/Việt) và tương thích nhiều kích thước màn hình.

## Tính năng
- Dự báo thời tiết theo vị trí
- Giao diện nhất quán, dễ sử dụng
- Hỗ trợ tiếng Anh và tiếng Việt
- Trang thông tin nhóm phát triển

## Cài đặt
1. Cài đặt Flutter SDK
2. Chạy lệnh:
   ```
   flutter pub get
   flutter run
   ```
